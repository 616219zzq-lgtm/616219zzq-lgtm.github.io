# 乡音 · 听见你的家乡

## 在线预览部署

GitHub Pages 可直接发布仓库根目录，保留已构建的 public 目录。在线版本支持页面交互、浏览器录音与本地保存；录音数据按浏览器独立保存。Python 语音识别、SQLite 数据同步与管理后台需要在本机服务运行，GitHub Pages 不运行这些接口。仓库不包含录音数据库、识别模型及本地依赖。

方言录音、文字确认、声音分析、声纹卡片与公共声音唱片画廊的本机交互网站。

## 启动

在访达中双击 `启动本机识别.command`，或在项目目录运行：

```sh
.venv/bin/python asr_server.py
```

打开 http://127.0.0.1:4173/ 。服务直接以本项目目录为网站根目录，地址中无需添加“乡音”。首次使用启动脚本时，会安装识别依赖并下载模型。

`/api/health` 返回模型文件是否就绪。录音识别由本机 TeleSpeech 模型处理；普通静态服务器只能预览页面，不能处理 `/api/transcribe`。

## 文件入口

- `index.html`、`styles.css`、`theme-light.css`、`app.js`：主体验与录音流程。
- `sticker-heading.js`、`assets/heading/`：首页标题贴纸交互。
- `src/gallery/`：React、Three.js 与 GSAP 唱片画廊源码。
- `public/gallery.html`、`public/assets/`：主页嵌入的画廊构建产物。
- `asr_server.py`：网页服务与本机语音识别接口。

修改画廊源码后运行：

```sh
npm run build:gallery
```

主页面使用项目根目录中的最新文件。`index.previous.html`、`.backups/` 以及 `public/home.html` 是历史副本，不作为主页面编辑入口。录音与声音墙数据保存在当前浏览器本机存储中；不同端口或浏览器的数据独立。

## 更新后的话题与唱片流程

详见交互流程规划.md。四个固定话题 × 12 个方言类别，通过 record-catalog.json 映射正反面图案；assets/records/ 是当前临时预览素材。预览页和 3D 画廊共用映射，声音墙支持按话题切换、多段原声选择和翻面猜方言。

语音转写仍使用本机模型；方言类别只有词汇参考建议与用户确认，尚未接入声学方言分类模型。

## 数据管理后台 · 2026-11-13

打开 http://127.0.0.1:4173/admin 查看本机公开录音数据。支持数据概览、按话题与方言筛选、文字搜索、录音详情与试听、原音频下载和 CSV 导出。

公开录音在浏览器保存成功后异步同步到 SQLite，每 15 秒重试。历史公开录音需要在原浏览器访问一次前台，或在后台点击“导入本浏览器公开录音”；其他浏览器无法读取原浏览器的 IndexedDB。私人录音不会上传。同步失败不影响浏览器本地保存，后台仅显示已成功同步的数据。

数据库位于 .data/voices.sqlite3，包含公开录音元数据和原始音频，重启服务后仍保留。备份前请停止服务并复制整个 .data 目录。该管理后台随本机服务运行，仅监听 127.0.0.1，尚未添加账号登录，不作为公网部署版本。

验证后端可运行 .venv/bin/python scripts/check-backend.py，测试使用临时数据库，不会污染真实记录。

## 独立地区选择 · 2026-11-16

识别确认页只校正录音文字；确认后进入独立重力标签地区选择页，短按标签进入声纹结果页，拖动与抛掷不会触发选区。支持键盘 Tab、Enter 和空格。地区目录与唱片素材共用 record-catalog.json，继续排除已移除的“闽南·潮汕”，共 14 个可选项。声纹页返回地区选择页，地区选择页返回文字确认页。

重力物理引擎源于提供的 gravity-tag-pile，项目内源码在 src/dialect-pile；构建仍用 npm run build:gallery，主页面嵌入 public/dialect-picker.html。运行 node scripts/check-dialect-step.cjs 检查步骤分离和地区消息映射。
